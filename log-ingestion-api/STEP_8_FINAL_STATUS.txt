🎓 LESSONS LEARNED & BEST PRACTICES

1. Timestamp Handling:
   - Different formats require flexible parsing strategies
   - Normalization to ISO 8601 enables consistency

2. Multi-field Data:
   - Some applications encode multiple metrics in single fields
   - Post-parse extraction and metadata population required

3. Component Naming:
   - Component identifiers vary widely (simple vs. complex)
   - Robust regex patterns essential for flexibility

4. Event Grouping:
   - Domain-specific categorization critical
   - Generic "SYSTEM" group for unknown types

5. State Management:
   - Per-device isolation prevents false correlations
   - Independent state crucial for accuracy
